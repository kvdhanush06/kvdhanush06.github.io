# Security Policy

This repository contains the source for the personal portfolio of Venkata Dhanush Kakarlamudi.

## Reporting a Vulnerability

Please report security vulnerabilities privately to the repository owner through GitHub or the contact information published on https://allkvd.dev/. Do not publish exploitable details in a public issue.

Include the affected component, reproduction steps, impact, and relevant evidence.

## Security Practices

- The portfolio is a static website and does not require a server-side database.
- Public profile links and project links are intentionally explicit and reviewable.
- Structured data is limited to public professional information.
- Client-side scripts should avoid unsafe HTML injection and unnecessary third-party dependencies.
- Secrets must never be included in source or generated static assets.

## Secret Handling

Never commit API keys, access tokens, private credentials, or deployment secrets.
